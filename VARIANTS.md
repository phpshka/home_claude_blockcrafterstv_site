# Варианты дизайна BlockCraftersTV

## ☀️ Sunny Voxel (default, v1.1.0.0+)

Файл: `style-variant5-sunny-voxel.css`
Шрифт: Pixelify Sans (с поддержкой кириллицы)
Палитра: небо #87ceeb · трава #5cb02e · солнце #ffe066 · дерево #6b3e1a · бумага #fffacd

Особенности:
- Дневной градиент неба → травы → земли в hero
- Пиксельные SVG-декорации (солнце, два облака, дерево, крипер)
- Полоса пиксельной травы поверх стыка травы и земли
- Все углы прямые, тени — смещённые блоки 4-7px
- prefers-reduced-motion: отключает hover-transforms

Подходит для: дневной аудитории, фанатов ванильного MC, child-friendly.

---

Доступно 2 варианта дизайна для сайта:

## 🟣 Вариант 1: Dark Gaming Premium
**Файлы:** `style-variant1-dark-gaming.css`, `index-variant1-dark-gaming.html`

### Особенности:
- **Цвета:** Фиолетовый (#8b5cf6) и Оранжевый (#f59e0b)
- **Стиль:** Премиум игровой дизайн с элегантными градиентами
- **Фон:** Чистый черный с едва заметной текстурой
- **Шрифты:** Inter для заголовков, Rajdhani для текста
- **Эффекты:** Мягкие свечения, профессиональные тени

### Использование:
```bash
# Переключиться на Вариант 1
cp style-variant1-dark-gaming.css style.css
cp index-variant1-dark-gaming.html index.html
```

---

## 🔵 Вариант 2: Neon Cyberpunk (ТЕКУЩИЙ)
**Файлы:** `style.css`, `index.html`

### Особенности:
- **Цвета:** Неоновый Циан (#00f8ff) и Магента (#ff00ff)
- **Стиль:** Киберпанк с яркими неоновыми эффектами
- **Фон:** Темный синий с неоновыми градиентами и сеткой
- **Шрифты:** Orbitron для заголовков, Rajdhani для текста
- **Эффекты:** Яркие неоновые свечения, двойные тени, 2px borders

### Эффекты:
- ✨ Неоновые borders на всех карточках
- 💫 Двойные неоновые свечения (cyan + magenta)
- 🌟 Пульсирующие status indicators
- 🎨 Градиентные кнопки с неоновым эффектом
- 🔮 Футуристичные иконки с свечением при hover
- ⚡ Усиленные hover анимации

### Использование:
Уже активен! Текущие файлы `style.css` и `index.html`

## Переключение между вариантами

### На Вариант 1 (Dark Gaming Premium):
```bash
cd /home/suppo/projects/BlockCraftersTV_site
cp style-variant1-dark-gaming.css style.css
cp index-variant1-dark-gaming.html index.html
```

### На Вариант 2 (Neon Cyberpunk):
Если вы переключились на Вариант 1 и хотите вернуться:
```bash
cd /home/suppo/projects/BlockCraftersTV_site
# Сначала сохраните текущий Вариант 2, если еще не сделали
cp style.css style-variant2-neon-cyberpunk.css
cp index.html index-variant2-neon-cyberpunk.html
```

## Рекомендации

- **Вариант 1** подходит для более серьезной, профессиональной аудитории
- **Вариант 2** идеален для молодой аудитории, любящей яркие визуальные эффекты
- Оба варианта полностью адаптивны и работают на всех устройствах
- Можно легко переключаться между вариантами в любое время

**Примечание:** При переключении вариантов убедитесь, что обновили браузер (Ctrl+F5) для очистки кэша.
