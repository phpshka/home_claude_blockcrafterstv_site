## Уроки сессии
1. **Cascade leaks от base style.css** — главный риск при добавлении CSS-overlay темы. Нужно ОБЯЗАТЕЛЬНО читать base CSS для каждого селектора, не полагаться только на план. Особенно опасны: `-webkit-text-fill-color: transparent`, `animation: ...` keyframes, `scale/rotate` на hover, `backdrop-filter: blur`.
2. **Press Start 2P + кириллица** — широко известная ловушка: пиксельный шрифт на Google Fonts только с латиницей. Visual-companion mockup-ы маскировали эту проблему (браузерный fallback подсовывал monospace). Должны были проверить раньше.
3. **Subagent-driven-development** работает хорошо для механических задач — implementer'ы быстро адаптировались к паттерну «найди leaks → reset». Reviewer'ы ловили реальные дефекты в каждой задаче. Двух-стадийный review (spec compliance + code quality) поймал и cascade leaks, и архитектурные риски (например, `.hero { height: 100vh }` lock).
4. **Visual Companion** для дизайн-обсуждений — намного эффективнее текстовых пунктов «A/B/C». Пользователь видит реальный визуал и кликает — turnaround быстрее, понимание точнее.
